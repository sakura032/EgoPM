只处理 `items`；每项仅据自身的 `transcript`、`dense_caption` 与 `visible_text` 返回一项，`n` 必须从 `0` 连续且各一次。仅输出 `n,f,start,end,p,c,v,e,s,a,r`：`f` 必须明确证据字段，`T` 表示 `transcript`、`D` 表示 `dense_caption`、`V` 表示 `visible_text`；`start,end` 是同一项中由 `f` 选择字段的 Unicode code-point 偏移，零基、左闭右开，必须满足 `0 <= start < end <= 该字段长度`。不要输出证据文本；程序会按位置从原字段切出原文。`p` 是 `[槽位,操作,值]`，槽位为 `T/P/L/O/A/S`，操作为 `=,!,+,-,^,$,~`；`p[0]` 必须是主 cue 类型，后续最多两项为附加条件；`c` 为 `0..100`；`v` 为 `A/R/N`。`e,s,a,r` 可省略。禁止 `t`、`x`、ID、split、原文副本、模型、路径和其他字段；不得借用其他项文本。字段值为 `null` 时不得选择该字段。
